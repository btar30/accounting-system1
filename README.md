# 📊 Enterprise Accounting & Banking System

A robust, enterprise-grade backend financial and accounting system built with **Java 21** and **Spring Boot**, featuring secure role-based access control, double-entry journal processing, and comprehensive financial reporting.

---

## 🚀 Core Features

- **Double-Entry Accounting & Journal Management**: Automated validation for balanced debit and credit entries.
- **Chart of Accounts (CoA)**: Hierarchical account management and structured categorization (Assets, Liabilities, Equity, Revenues, Expenses).
- **Financial & Ledger Reports**: Automated generation of trial balances, income statements, and account ledger statements.
- **Inventory & Invoicing**: Complete modules for managing sales invoices, purchase invoices, and item stocks.
- **Customer & Supplier Management**: Comprehensive tracking and management of client and vendor records.
- **Security & Authentication**: Stateless JWT (JSON Web Token) authentication and authorization using Spring Security.
- **RESTful APIs**: Well-structured endpoints tested and documented for seamless integration.

---

## 🛠️ Tech Stack

- **Language**: Java 21
- **Framework**: Spring Boot
- **Data Persistence**: Spring Data JPA, Hibernate
- **Database**: Microsoft SQL Server / MySQL
- **Security**: Spring Security, JWT
- **Build Tool**: Maven
